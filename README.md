# SWD Craftworks official website

Static website hosted on GitHub Pages.

## Publish
Upload the contents of this folder (not the parent folder) to the root of the `swdcraftworks.github.io` repository. Under Settings → Pages, use `Deploy from a branch`, `main`, `/ (root)`.

## Before publishing
Review all text, especially the privacy policy, to ensure it matches actual website operation. The privacy policy is for the website only, not for individual Android apps.

## Custom domain
After obtaining a domain, follow the official GitHub Pages custom-domain instructions and configure DNS at the registrar. Do not change links here; all internal links are root-relative only where appropriate? All site links use relative paths for both GitHub Pages and a custom domain.
